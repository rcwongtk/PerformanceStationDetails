# Performance Station pitch page

A buildless, responsive page by Modelcentric. All footage is embedded directly from the supplied Vimeo videos. No contact form, pricing, fixed offer, analytics, or accounts are included.

## GitHub Pages

Publish the contents of `dist/` at the root of a GitHub Pages repository. Assets use relative paths, so the page also works under a repository subpath. No build step or server is required. The `.openai` folder is only used by the current review hosting and is not required on GitHub Pages.

## Updates

- Edit page text in `dist/index.html` and styling in `dist/style.css`.
- Vimeo IDs are stored in `data-video` and `data-id` attributes. Camera/gameplay buttons change the displayed video. Videos only load after a visitor presses play.
- Replace posters in `dist/assets/` to update preview images.
- The Breathe Parkour case study is attributed feedback, not evidence of measured performance improvements.
- Add future case studies as new sections using the existing case-study layout.
